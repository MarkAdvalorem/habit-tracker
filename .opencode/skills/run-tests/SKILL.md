## What I do
- Run `pnpm check` to verify TypeScript types
- Run `pnpm lint` to check for ESLint issues
- Run `pnpm test` to execute all vitest tests
- Display results for each step
- If any step fails, report the specific errors and suggest potential fixes
- Continue through all steps even if one fails (to show full picture)

## When to use me
Use this skill after code changes to verify everything passes, or when the user asks to run tests, check types, or lint.
